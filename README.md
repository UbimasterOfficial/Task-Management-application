# CloudTask - Task Management Platform

> 🚧 **Project Status: Ongoing Development**

CloudTask is a simple **MERN Stack Task Management application** developed as part of my **DevOps Engineer Internship Final Project**.

The application allows users to create and manage tasks through a modern web interface. The main purpose of this project is to build a working application first and then implement a complete DevOps workflow around it.

## Application Features

* Create new tasks
* View all tasks
* Update task status
* Delete tasks
* Filter tasks by status
* Task priority management
* Application health check through `/health`
* Application and HTTP request logging
* Basic automated API testing
* Code quality checking with ESLint

## Technology Stack

## Project Goal

The final goal of this project is to take the application through a complete DevOps lifecycle:

`Application Development → Testing → Containerization → CI/CD → Deployment → Monitoring`

The project will gradually include technologies such as Docker, GitHub Actions, Kubernetes, Terraform, AWS, and monitoring tools.

## Current Progress

The project is currently under active development. Features and DevOps components will be added step by step as the project progresses.
